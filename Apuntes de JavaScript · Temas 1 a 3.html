1. Introducción y variables

Al terminar este tema sabrás:
  • Qué es JavaScript y dónde se ejecuta.
  • Probar código en la consola.
  • Guardar datos con let y const.
  • Saber en qué parte del código existe cada variable (el ámbito).

JavaScript es un lenguaje que se ejecuta en el navegador, en el servidor (Node.js) y en aplicaciones móviles y de escritorio. No tiene relación con Java más allá del nombre.

Para probar código abre la consola del navegador con la tecla F12.

Ejemplo A. Saludo con variables

const nombre = 'Lucía';   // texto: va entre comillas
let puntos = 0;           // número: puede cambiar
puntos = puntos + 10;     // ahora vale 10
console.log('Hola, ' + nombre);
console.log('Tienes ' + puntos + ' puntos');
  1. Se guarda el texto en nombre.
  2. Se guarda 0 en puntos.
  3. Se suma 10 y se guarda en la misma variable.
  4. Se muestran dos mensajes en la consola.
Idea clave
La diferencia no es si «el valor cambia», sino si puedes reasignar la variable con =, es decir, hacer que apunte a otro valor. Con let puedes. Con const no.

Ejemplo B. Un error muy típico

const edad = 18;
edad = 19; // TypeError: Assignment to constant variable.
Ojo
No puedes asignar otro valor a una variable const. Si ves este error y de verdad necesitas reasignarla, declárala con let.

Ejemplo C. const con arrays y objetos

const frutas = ['pera', 'uva'];   // frutas guarda la dirección de memoria del array

frutas.push('kiwi');     // permitido: cambia el contenido
frutas[0] = 'manzana';   // permitido: cambia un elemento
console.log(frutas);     // ['manzana', 'uva', 'kiwi']

frutas = ['limón'];      // ERROR: la variable apuntaría a otro array
  1. Un array no se guarda dentro de la variable. Se guarda en una zona de la memoria y la variable guarda la dirección de esa zona, es decir, apunta a ella.
  2. const impide cambiar esa dirección: la variable no puede apuntar a otro array distinto.
  3. Los elementos del array sí pueden cambiar, porque la dirección sigue siendo la misma. Por eso los arrays y los objetos se declaran con const.
  4. Con números y textos la variable guarda el valor directamente, así que con const ese valor no puede cambiar: const edad = 18.

Ejemplo D. Cuándo hace falta let

let total = 0;
total = total + 5;   // reasignación: aquí necesitas let
total = total + 10;  // total vale 15
SituaciónUso
La variable se reasigna con = (un contador, una suma, un valor que se sustituye)let
La variable no se reasigna, aunque cambie el contenido de un array u objetoconst

Ejemplo E. El ámbito de let y const

El ámbito es la zona del código donde existe una variable. Con let y const el ámbito es el bloque: todo lo que queda entre llaves { }.

let mensaje = 'Fuera del bloque';

if (true) {
  let secreto = 'Solo existe aquí';
  console.log(secreto);   // 'Solo existe aquí'
  console.log(mensaje);   // 'Fuera del bloque' (desde dentro se ve lo de fuera)
}

console.log(secreto);     // ERROR: secreto is not defined
  1. secreto nace al declararla dentro de las llaves y desaparece al cerrarlas.
  2. Desde dentro de un bloque puedes ver las variables de fuera.
  3. Desde fuera no puedes ver las variables de dentro.
Idea clave
Una variable declarada con let o const solo existe dentro de las llaves donde se declara.

Ejemplo F. El ámbito en un bucle

for (let i = 0; i < 3; i++) {
  console.log(i);   // 0, 1, 2
}

console.log(i);     // ERROR: i is not defined

La variable i pertenece al bloque del for y desaparece cuando el bucle termina.

Ejemplo G. Mismo nombre en bloques distintos

let nombre = 'Ana';

{
  let nombre = 'Luis';    // es otra variable distinta
  console.log(nombre);    // 'Luis'
}

console.log(nombre);      // 'Ana'
Ojo
Si declaras una variable dentro de un if o de un bucle y la usas fuera, obtienes un error. Declárala antes, fuera del bloque. Con var (la forma antigua) el ámbito no es de bloque, y por eso se evita.

  • Comparar con ===.
  • Convertir texto en número.

Ejemplo A. Sumar o concatenar

const texto = '5';
const numero = 5;
console.log(texto + numero);          // '55' (junta textos)
console.log(Number(texto) + numero);  // 10   (suma números)
Ojo
prompt siempre devuelve texto, aunque el usuario escriba un número. Convierte con Number() antes de operar.

Ejemplo B. Comparaciones

console.log(5 > 3);       // true
console.log(5 === '5');   // false (distinto tipo)
console.log(5 == '5');    // true  (evítalo)
console.log(10 % 3);      // 1 (resto de la división)
Idea clave
Usa siempre === y !==.

3. Condicionales

Al terminar este tema sabrás:
  • Decidir con if, else if y else.
  • Elegir con switch.
  • Combinar condiciones con &&, || y !.

Sintaxis de cada estructura

Hay cinco formas de tomar decisiones. Para cada una verás primero la sintaxis (el molde) y después un ejemplo real.

1. if

Ejecuta un bloque solo si la condición es verdadera.

if (condición) {
  // se ejecuta si la condición es verdadera
}
const edad = 20;

if (edad >= 18) {
  console.log('Eres mayor de edad');
}

2. if...else

Elige entre dos caminos: uno si se cumple y otro si no.

if (condición) {
  // si es verdadera
} else {
  // si es falsa
}
const nota = 4;

if (nota >= 5) {
  console.log('Aprobado');
} else {
  console.log('Suspenso');
}

3. if...else if...else

Elige entre varios caminos. Se prueban en orden y se ejecuta solo el primero que se cumple.

if (condición1) {
  // si se cumple la 1
} else if (condición2) {
  // si no la 1, pero sí la 2
} else {
  // si no se cumple ninguna
}
const hora = 17;

if (hora < 12) {
  console.log('Buenos días');
} else if (hora < 20) {
  console.log('Buenas tardes');
} else {
  console.log('Buenas noches');
}

4. switch

Compara una variable con varios valores exactos.

switch (variable) {
  case valor1:
    // si variable === valor1
    break;
  case valor2:
    // si variable === valor2
    break;
  default:
    // si no coincide ninguno
}
const opcion = 'b';

switch (opcion) {
  case 'a':
    console.log('Has elegido A');
    break;
  case 'b':
    console.log('Has elegido B');
    break;
  default:
    console.log('Opción no válida');
}

5. Operador ternario

Es un if...else en una sola línea que devuelve un valor.

condición ? valorSiVerdadero : valorSiFalso;
const edad = 15;
const mensaje = edad >= 18 ? 'Mayor de edad' : 'Menor de edad';
console.log(mensaje); // 'Menor de edad'

¿Cuál uso en cada caso?

SituaciónEstructura
Hacer algo solo si se cumple una condiciónif
Dos caminos posiblesif...else
Varios rangos o condiciones distintasif...else if...else
Comparar una variable con valores exactosswitch
Elegir un valor corto para guardarlo en una variableTernario
Idea clave
Con if puedes usar cualquier condición (>, <, &&...). Con switch solo comparas valores exactos.

Ejemplo A. Un semáforo

const color = 'rojo';

if (color === 'verde') {
  console.log('Puedes pasar');
} else if (color === 'ámbar') {
  console.log('Precaución');
} else {
  console.log('Detente');
}
  1. Se comprueban las condiciones en orden.
  2. Se ejecuta la primera que sea verdadera y se salta el resto.
  3. Si ninguna se cumple, se ejecuta el else.

Ejemplo B. Combinar condiciones

const edad = 16;
const tieneEntrada = true;

if (edad >= 12 && tieneEntrada) {
  console.log('Puedes pasar');
}
  • && significa y: las dos deben cumplirse.
  • || significa o: basta con una.
  • ! significa no: invierte el valor.

Ejemplo C. Elegir con switch

const dia = 3;
let nombreDia;

switch (dia) {
  case 1:
    nombreDia = 'lunes';
    break;
  case 3:
    nombreDia = 'miércoles';
    break;
  default:
    nombreDia = 'otro día';
}
Ojo
Si olvidas break, la ejecución sigue en el case siguiente.
Pruébalo
Pide una nota con prompt y muestra si es suspenso, aprobado, notable o sobresaliente.
